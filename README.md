## Tujuan

Tujuan dari tugas ini adalah menggunakan perulangan `for` dan `while` untuk menyelesaikan masalah yang membutuhkan proses secara berulang. `for` digunakan ketika jumlah perulangan sudah diketahui, sedangkan `while` digunakan ketika perulangan bergantung pada suatu kondisi.
